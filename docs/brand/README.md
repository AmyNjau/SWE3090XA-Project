# USIU-Africa brand assets

Used for the cover page and running header of every report in this project.

## Logos

| File | Use |
|------|-----|
| `usiu-logo.png` | Full-colour logo with tagline, 1125×600. Cover page and page header on white. |
| `usiu-logo-white.png` | White knockout, 1125×600. Only on the deep-blue band. |

Both downloaded from the official university site, `www.usiu.ac.ke`
(`/wp-content/uploads/2020/02/Correct-USIU-Logo-with-Tagline-01-01.png` and
`/wp-content/uploads/2025/10/USIU-Logo-with-Tagline-01-white.png`) on 2026-08-09.

> `brandfetch.com/usiu.ac.ke` returns 404 — the university's own site is the
> authoritative source and is what these files came from.

## Palette

Sampled from the official logo (most frequent non-white pixels), so these are the
real brand values rather than an approximation:

| Token | Hex | Role |
|-------|-----|------|
| USIU Blue | `#204098` | Headings, cover band, table header fill, rules |
| USIU Blue (dark) | `#283890` | Secondary headings, hyperlinks |
| USIU Gold | `#F8C808` | Accent rule under headings, key callouts. Use sparingly |
| Ink | `#201820` | Body text |
| Grey | `#5B6B82` | Captions, table secondary text |

Gold on white fails contrast for body text — use it only as a rule, fill, or
accent behind dark text, never as text on white.

## Document conventions

- Logo top-left of the cover, and in the running header of every page after it.
- Cover carries: university, school, course code and title, project title,
  student name and ID, supervisor, and submission date.
- Body: Calibri 11pt, 1.15 line spacing. Headings in USIU Blue.
- Every figure and table numbered and captioned; captions in Grey.
